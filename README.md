# SbaizMetal

Landing page estática para una empresa de estructuras metálicas y herrería de obra.

## Estructura

- `index.html`
- `styles.css`
- `script.js`
- `assets/logo3.png`

## Deploy en Netlify

1. Subir el proyecto a GitHub.
2. Conectar el repositorio en Netlify.
3. Dejar vacío el campo `Build command`.
4. Configurar `Publish directory` con `/`.
5. Cada `git push` actualizará la web automáticamente.

## Desarrollo local

Abrí `index.html` directamente en el navegador o serví la carpeta con cualquier servidor estático.
